   153→## 🌟 Mengapa MUHDIN Ada?
   154→
   155→Jutaan jamaah Indonesia berangkat setiap tahun — namun ekosistemnya masih terfragmentasi: data travel tersebar di PDF Kemenag, verifikasi lisensi manual, komunikasi via WhatsApp, dan jamaah sering tak tahu operatornya legal atau tidak.
   156→
   157→> 🏛️ **Bukan pendatang** — MUHDIN mewarisi garis pelopor **PHI & IPHI**, penyelenggara haji & umrah pertama di Nusantara sebelum Kemenag RI, dengan **blueprint karya abadi** para pengurus pusatnya. Baca [Warisan dan Garis Waktu](#️-warisan-dan-garis-waktu).
   158→
   159→| 😩 **Masalah Nyata** | ✅ **Solusi MUHDIN** |
   160→|---|---|
   161→| Data penyelenggara tersebar di PDF & spreadsheet statis | 📚 **Direktori anggota live** — filter instan per tipe/provinsi/kota, pencarian real-time, halaman profil + verifikasi lisensi publik |
   162→| Jamaah sulit memastikan PPIU/PIHK legal | 🛡️ **Halaman verifikasi lisensi** per anggota — nomor izin, status, rating, tampil publik |
   163→| Tidak ada jembatan ke sistem Nusuk Saudi | 🕌 **Nusuk Hub** — koneksi API SANDBOX/PRODUCTION, katalog izin (Tasreeh, Raudah, dst.), sinkronisasi, webhook, metrics |
   164→| Konten & pengumuman tak terorganisir | ✍️ **CMS lengkap** — berita, tutorial, agenda, galeri, FAQ dengan draft→publish |
   165→| Komunikasi satu arah, tak teraudit | 📜 **Audit log penuh** — setiap aksi admin terekam (LOGIN, CREATE, VERIFY, …) |
   166→| Bahasa jadi penghalang jamaah mancanegara | 🌍 **3 bahasa aktif** — Indonesia · English · العربية dengan RTL sungguhan |
   167→| Akses dari perangkat lawas & sinyal lemah di Makkah | 📱 **PWA offline-ready** + hash routing super-ringan |
   168→| Hosting mahal & rumit | 🐘 **Edisi PHP tanpa Node.js** — cukup shared hosting cPanel biasa (lihat [Deployment](#-deployment)) |
   169→
   170→> *"Syurga bagi pengusaha pelayan Tamu Allah dan kenyamanan jamaah dalam ibadah."*

   306→    subgraph K2["💻 Browser / PWA (frontend sama persis)"]
   307→        UI2["React 19 SPA — static export"]
   308→    end
   309→    subgraph APACHE["🐘 Apache / LiteSpeed (cPanel)"]
   310→        HT[".htaccess — rewrite /api/* + proteksi data"]
   311→        PHP["🐘 api/index.php — router modul<br/>routes-auth · routes-content<br/>routes-directory · routes-nusuk"]
   312→        LIB["lib.php — sesi DB · guard RBAC<br/>rate-limit SQLite · WA · i18n cache"]
   313→        NSK["nusuk.php — katalog izin · sync · webhook"]
   314→    end
   315→    DB2[("🗄️ muhdin.sqlite — skema sama<br/>DateTime = epoch ms")]

   317→    PHP --> NSK --> DB2
   318→```
   319→
   320→**Keputusan arsitektur (mengapa begini):**
   321→
   322→1. **Satu `app/page.tsx` + hash router kustom** (`useSyncExternalStore`) — SPA murni melayani 16 rute tanpa konfigurasi rewrite server. Berjalan di cPanel, Nginx, Apache, bahkan static host.
   323→2. **API layer seragam** — setiap endpoint melewati `ok()`/`fail()` untuk format respons, guard peran untuk RBAC server-side, `logAudit()` untuk jejak, dan `applyEntityTranslations()` untuk i18n konten. Kedua mesin (Node & PHP) mengikuti kontrak yang sama persis — teks error pun identik.
   324→3. **Aset maskapai self-hosted** — logo diunduh, divalidasi magic-bytes, disimpan lokal (tanpa hotlink CDN pihak ketiga) → aman untuk produksi, cepat, dan menghormati bandwidth hosting.
   325→4. **SQLite + Prisma** — zero-config, satu file mudah dibackup, dan 100% kompatibel shared hosting. Butuh skala besar? Cukup ganti `provider` di schema → `db:push`.
   326→5. **Dual-mode build** — `BUILD_STATIC=1` menghasilkan static export murni untuk edisi PHP; mode default menghasilkan `standalone` Node dengan fitur AI terjemahan inline. Dua paket deploy dari satu codebase.
   327→6. **Prisma 6 menyimpan DateTime sebagai INTEGER epoch-ms** — backend PHP menulis & menormalkan format yang sama (`cast_row`), sehingga **database yang sama bisa dibaca-tulis kedua mesin** (terverifikasi uji silang).

   686→## 🔐 Keamanan dan Kontrol Akses (RBAC)
   687→
   688→**Hierarki peran** (semakin besar level, semakin luas kewenangan):
   689→
   690→```mermaid
   691→flowchart LR
   692→    SA["👑 SUPER_ADMIN<br/>level 100"] --> AD["🛡️ ADMIN<br/>level 80"] --> VF["✅ VERIFIKATOR<br/>level 60"] --> ED["✍️ EDITOR<br/>level 40"]
   693→```
   694→
   695→**Matriks modul CMS** (dari `src/lib/roles.ts` — dieksekusi server-side, bukan cuma UI):
   696→
   697→| Modul | SUPER_ADMIN | ADMIN | VERIFIKATOR | EDITOR |
   698→|---|:---:|:---:|:---:|:---:|
   699→| Dashboard | ✅ | ✅ | ✅ | ✅ |
   700→| Nusuk · Pesan · Subscriber · Pengaturan | ✅ | ✅ | — | — |
   701→| Artikel · Ekosistem · Alur · Roadmap · Tutorial · FAQ · Testimoni · Pengurus · Cabang · Galeri · Agenda · Unduhan · Translator | ✅ | ✅ | — | ✅ |
   702→| Anggota · Pendaftaran · Pengaduan | ✅ | ✅ | ✅ | — |
   703→| Audit Log · Kelola Pengguna | ✅ | — | — | — |
   704→
   705→**Lapisan keamanan bawaan:**
   706→
   707→- 🔐 Password **scrypt** (Node) / **bcrypt** (PHP) — tidak ada plaintext di database
   708→- 🍪 Session cookie **httpOnly + SameSite=Lax** (kedaluwarsa 7 hari, token 64-hex acak) — **nama cookie sama di kedua mesin**: `muhdin_session`
   709→- 🛡️ **RBAC server-side** di seluruh endpoint admin — UI hanya lapisan kenyamanan
   710→- 🚦 **Rate limit** — login 5/menit (Node in-memory · PHP tabel SQLite) → 429
   711→- 📜 **Audit log otomatis** — `LOGIN · LOGOUT · CREATE · UPDATE · DELETE · VERIFY · SYNC · JOIN · CONTACT · EXPORT`
   712→- 🧬 Query **parameterized** — Prisma di Node, prepared statement PDO di PHP — bebas SQL injection
   713→- ✍️ **Webhook Nusuk terverifikasi tanda tangan** (secret/HMAC, `hash_equals`)
   714→- 📦 Logo maskapai self-hosted — tanpa hotlink & jejak pihak ketiga
   715→- 🚫 `.htaccess` memblokir unduhan `.sqlite` & dotfiles di edisi hosting
   716→
   717→```ts
   718→// Contoh guard di route.ts (pola nyata proyek ini):
   719→await requireSession(req);                    // 401 bila tanpa sesi
   720→await guardRole(req, ["SUPER_ADMIN", "ADMIN"]); // 403 bila peran tak berizin
   721→await logAudit(req, "VERIFY", "Member", id);  // jejak otomatis
   722→```

   754→## 📦 Deployment
   755→
   756→### Opsi A — Shared Hosting PHP Edition (TANPA Node.js) ⭐ v3.0
   757→
   758→**Inilah yang paling revolusioner**: MUHDIN berjalan penuh — portal publik + CMS admin + Nusuk Hub + verifikasi + audit — di shared hosting cPanel biasa **tanpa Node.js, tanpa MySQL, tanpa SSH, tanpa Composer**. Frontend statis murni + backend API PHP + SQLite:
   759→
   760→```mermaid
   761→flowchart LR
   762→    B["🌐 Browser"] --> A["Apache / LiteSpeed
   763→(cPanel)"]
   764→    A -->|"/_next, ikon, PWA"| S["📁 Berkas statis
   765→index.html + aset"]
   766→    A -->|"/api/* rewrite"| P["🐘 api/index.php
   767→63 endpoint paritas Node"]
   768→    P --> D[("🗄️ muhdin.sqlite
   769→PDO SQLite")]
   770→    P -.->|"fire-and-forget"| W["💬 Gateway WhatsApp
   771→Fonnte · Wablas · Custom"]
   772→```
   773→
   774→```bash
   775→bun run hosting:build     # → deploy/muhdin-shared-hosting/ (5,6 MB) + zip (±3,2 MB!)
   776→```
   777→
   778→Yang dilakukan pipeline `build-shared-hosting.mjs` secara otomatis:
   779→
   780→1. **Salinan proyek terisolasi** di `/tmp` — proyek utama & dev server tidak disentuh sama sekali.
   781→2. `next build` dengan `BUILD_STATIC=1` → **static export** murni (HTML+JS+CSS — hash routing tetap berfungsi penuh).
   782→3. Rakit paket: frontend statis + `api/*.php` (8 berkas, **6.188 baris** — replika 1:1 kontrak 63 route Node) + `data/muhdin.sqlite` + `.htaccess` (routing + proteksi DB) + `INSTALL.txt` Bahasa Indonesia.
   783→4. **Re-hash password akun demo ke bcrypt** agar login demo langsung berfungsi di PHP.
   784→5. Zip siap unggah — **±3,2 MB** (28× lebih ramping dari paket Node 90 MB; nol runtime Node).
   785→
   786→**Cara pasang (±5 menit)**: unggah zip ke `public_html` → Extract → selesai. Verifikasi `https://domain/api/health` → `{"ok":true,...}`. Lalu **ganti password 3 akun demo** (wajib).
   787→
   788→| Aspek | Keterangan |
   789→|---|---|
   790→| Prasyarat | PHP 7.4+ dengan `pdo_sqlite` (bawaan cPanel) — **itu saja** |
   791→| Struktur backend | `index.php` (router) + `config.php` + `lib.php` (sesi, guard, rate-limit, WA, i18n cache) + `nusuk.php` (mesin Nusuk) + `routes-{auth,content,directory,nusuk}.php` (modul rute) |
   792→| Paritas API | Seluruh kontrak Node direplikasi: sesi DB + cookie sama (`muhdin_session`), RBAC 4 peran, audit, rate-limit SQLite, WhatsApp 3 provider, i18n konten, Nusuk engine, CSV export, RSS, webhook signature |
   793→| Kompatibilitas dua arah | PHP menulis **epoch ms** persis Prisma; Prisma membaca baris tulisan PHP tanpa keluhan (terverifikasi uji silang) |
   794→| Akun demo | 3 akun demo di-rehash ke bcrypt otomatis saat build; akun lain cukup di-reset lewat CMS oleh Super Admin |
   795→| Degradasi anggun | Terjemahan AI inline tidak tersedia (butuh Node) — konten EN/AR tetap dilayani dari cache `ContentTranslation`; teks sumber Indonesia jadi fallback |
   796→| Keamanan | `.htaccess` memblokir unduhan `.sqlite`/dotfiles; header keamanan; pesan error identik versi Node |
   797→| Pratinjau lokal | `php -S 0.0.0.0:3010 -t deploy/muhdin-shared-hosting shared-hosting/router.php` |

   895→## 🔧 Troubleshooting
   896→
   897→| Gejala | Penyebab & Solusi |
   898→|---|---|
   899→| **Hydration mismatch / UI lama** | Bundle Turbopack basi → `pkill -f "next dev"; rm -rf .next; bun run dev` |
   900→| **500 semua API (Node)** | DB pindah schema → `bun run db:push` lalu restart dev server |
   901→| **Login admin gagal** | Pastikan seed sudah jalan: `bun prisma/seed.ts` |
   902→| **Logo maskapai 404** | `bun scripts/fetch-airline-logos.mjs` (atau `--force` untuk unduh ulang) |
   903→| **`db push` gagal relasi** | Pastikan relasi bolak-balik lengkap di schema (mis. `Member.permits` ↔ `NusukPermit.member`) |
   904→| **Prisma engine salah di hosting** | Paket hosting Node sudah menyertakan **dual engine** Debian+RHEL |
   905→| **Font Arab tidak muncul** | `next/font/google` butuh internet saat build pertama |
   906→| **Bahasa kembali ke Indonesia** | Pilihan tersimpan di cookie `muhdin-locale` — cek cookie browser tidak diblokir |
   907→| **Port 3000 terpakai** | `pkill -f "next-server"` lalu jalankan lagi |
   908→| **Pengurus tampil data lama** | Jalankan `bun scripts/update-management.mjs` |
   909→| **Edisi PHP: 500 / blank** | Cek versi PHP ≥ 7.4 & ekstensi `pdo_sqlite` aktif; pastikan `.htaccess` ikut terunggah (dotfile!) |
   910→| **Edisi PHP: 429** | Rate limit aktif (5 percobaan/menit) — tunggu 1 menit |
   911→| **Edisi PHP: akun tidak bisa login** | Akun dibuat di Node (scrypt) → reset password lewat CMS Super Admin (jadi bcrypt) |

   915→## ❓ FAQ
   916→
   917→<details>
   918→<summary><b>Benarkah MUHDIN bisa jalan di shared hosting TANPA Node.js?</b></summary>
   919→
   920→**Benar — sejak v2.0 dan kini makin matang di v3.0.** Jalankan `bun run hosting:build`, unggah zip ±3,2 MB ke `public_html`, extract — selesai. Backend API berpindah dari route Node ke **PHP + PDO SQLite** (`api/index.php` + modul `routes-*.php`) dengan kontrak yang identik: sesi, RBAC, audit, rate-limit, WhatsApp, Nusuk Hub, hingga ekspor CSV. Prasyaratnya satu: PHP 7.4+ dengan `pdo_sqlite` (bawaan semua cPanel). Satu-satunya fitur yang diturunkan adalah terjemahan AI *inline* (butuh Node) — konten EN/AR tetap dilayani dari cache database.
   921→</details>
   922→
   923→<details>
   924→<summary><b>Apakah MUHDIN bagian dari Nusuk (Kementerian Haji Saudi) atau Kemenag RI?</b></summary>
   925→
   926→**Tidak.** MUHDIN adalah asosiasi independen penyelenggara ibadah — pewaris garis pelopor PHI & IPHI. Integrasi Nusuk dilakukan lewat koneksi API resmi (SANDBOX/PRODUCTION) untuk melayani anggota.
   927→</details>
   928→
   929→<details>
   930→<summary><b>Apa makna PHI, IPHI, dan "blueprint karya abadi"?</b></summary>
   931→
   932→**PHI (Perjalanan Haji Indonesia)** dan **IPHI (Ikatan Persaudaraan Haji Indonesia)** adalah penyelenggara haji & umrah **pertama di Nusantara — sebelum Kementerian Agama RI berdiri (1946)**. **Blueprint haji & umrah Indonesia** adalah karya abadi para tokoh yang kini duduk di Pengurus Pusat MUHDIN — ditulis sebelum ada payung hukum. MUHDIN melanjutkan garis itu sebagai **asosiasi haji & umrah digital pertama di dunia**. Baca [Warisan dan Garis Waktu](#️-warisan-dan-garis-waktu).
   933→</details>
   934→
   935→<details>
   936→<summary><b>Berapa banyak data anggota bawaan?</b></summary>
   937→
   938→Database seed berisi **15 anggota contoh** (5 PPIU · 4 PIHK · 3 KBIHU · 2 Travel Wisata · 1 IPHI) tersebar di 8 provinsi & 10 kota — cukup untuk mendemokan seluruh alur: direktori, verifikasi lisensi, pendaftaran ber-tiket, dan Nusuk. Skema & CMS siap menampung ribuan anggota; tambahkan lewat CMS atau impor data Anda sendiri.
   939→</details>
   940→
   941→<details>
   942→<summary><b>Kenapa memilih SQLite, bukan PostgreSQL/MySQL?</b></summary>
   943→
   944→Zero-config, satu file (`db/custom.db`) mudah dibackup, dan 100% kompatibel shared hosting cPanel — bahkan edisi PHP tanpa Node pun jalan. Butuh skala besar? Cukup ganti `provider` di `prisma/schema.prisma` → `bun run db:push`.
   945→</details>
   946→
   947→<details>
   948→<summary><b>Kenapa hash-route (<code>#/admin</code>), bukan path biasa?</b></summary>
   949→
   950→SPA murni tanpa rewrite server — berjalan di cPanel, Nginx, Apache, atau static host apa pun tanpa konfigurasi tambahan. Plus navigasi instan tanpa full reload. Inilah yang membuat frontend statis edisi PHP bekerja identik dengan edisi Node.
   951→</details>
   952→
   953→<details>
   954→<summary><b>Bagaimana menambah bahasa baru (mis. Melayu, Mandarin)?</b></summary>
   955→
   956→Tambahkan blok bahasa di `src/lib/i18n/locales/*.ts` lalu daftarkan kodenya di `LocaleProvider` — RTL otomatis jika `dir` diset. Panduan lengkap di [bagian i18n](#-internasionalisasi).
   957→</details>
   958→
   959→<details>
   960→<summary><b>Aplikasi bisa dipakai offline?</b></summary>
   961→
   962→Ya. Sebagai **PWA**, shell aplikasi & halaman offline tersedia via service worker (`public/sw.js`) — pasang lewat menu "Install app" di browser. Service worker otomatis nonaktif di mode dev dan auto-update di produksi.
   963→</details>
   964→
   965→<details>
   966→<summary><b>Bagaimana menambahkan maskapai baru?</b></summary>
   967→
   968→Edit array `AIRLINES` di `scripts/fetch-airline-logos.mjs` (kode IATA + nama + negara + kawasan) → `bun scripts/fetch-airline-logos.mjs`. Logo otomatis diunduh & data ter-generate.
   969→</details>
   970→
   971→<details>
   972→<summary><b>Berapa spesifikasi hosting minimal?</b></summary>
   973→
   974→**Edisi PHP**: shared hosting mana pun dengan PHP 7.4+ & `pdo_sqlite` — paket hanya ±3,2 MB. **Edisi Node**: Node.js 20+, ±200 MB disk (paket standalone), tanpa database eksternal. Berjalan mulus di cPanel Entry-Level, Railway, Fly.io, hingga VPS 512 MB.
   975→</details>
   976→
   977→<details>
   978→<summary><b>Apakah data jamaah aman?</b></summary>
   979→
   980→Ya — hashing password (scrypt/bcrypt), cookie httpOnly, RBAC server-side, audit log penuh, query parameterized, webhook terverifikasi tanda tangan, dan rate limit. Data sensitif tidak pernah dikirim ke pihak ketiga.
   981→</details>
   982→
   983→<details>
   984→<summary><b>Bagaimana alur verifikasi anggota bekerja?</b></summary>
   985→
